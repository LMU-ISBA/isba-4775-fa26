# Student repository starters

> Archived sales-lab material. The current course builds a resume site in
> `career-platform`. Follow the [current resume-site guide](https://github.com/LMU-ISBA/isba-4775-fa26/blob/main/guides/resume-site-in-codespaces.md).
> This older starter and its `ex03/` folder are not the current Exercise 03.

The [portfolio starter](portfolio/README.md) supplies the files used in the
Session 5 portfolio setup. Its contents become the root of a student's
`isba-4775-portfolio` repository.

This is the local source for the
[portfolio template](https://github.com/LMU-ISBA/isba-4775-portfolio-template).
Follow the [portfolio guide](../guides/portfolio-repository.md) during class.

The template bundles copies of the two student guides so its instructions
are available from the starting repository. Refresh `portfolio/guides/` from
the course's `guides/` directory whenever those guides change, then update
the archive and template repository together.

The Python application is built during the lesson. The starter includes
the installation script, sample SQL, account setup, and writing prompts.
