# Sales application plan

> Archived sales-lab material. The current course builds a resume site in
> `career-platform`. Follow the [current resume-site guide](https://github.com/LMU-ISBA/isba-4775-fa26/blob/main/guides/resume-site-in-codespaces.md).
> This older starter and its `ex03/` folder are not the current Exercise 03.

Complete this plan during the AI interview, before building the application.

## Purpose

Identify who will use the page and what they need from the sales data.

## Request path

Describe the browser, GitHub forwarding, Python application, and MySQL server.
Label where each runs and which ports connect them. Show Nginx separately.

## Requirements and checks

Write the agreed behavior for a healthy database, an unavailable database,
and recovery. Include the expected rows and total and the checks you will run.

## Implementation steps

List the small build steps agreed with the coding agent. Identify the files
it will create and the configuration it will read.

## Follow-up change

Before adding count and average, record the new requirements and predicted
results. Explain what should happen if the table contains no sales.
