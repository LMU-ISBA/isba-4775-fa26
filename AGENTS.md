# Repository instructions

For any task involving student submissions, grading, or student feedback, read
[grading/AGENTS.md](grading/AGENTS.md) before evaluating work or preparing grades.
It contains the instructor's grading approach, file conventions, and feedback
style. Read it even when the task starts from the repository root.

The `grading/` directory is private and gitignored. Never commit its contents,
force-add them, or copy student information into tracked course materials.
The private guide must be carried over separately when moving to a new checkout;
it is not included in a Git clone.

## Student guides

Keep guides short, with a clear goal and a few actionable steps. Use simple,
memorable prompts that students can adapt. Avoid elaborate prompts and assumed
audiences, designs, or implementation details. Let the agent inspect the actual
project. Retain essential verification, deadlines, and recovery instructions,
but link existing guidance instead of repeating it. Keep instructor rehearsal
details in private planning files. Apply this check before publishing new or
revised guides. See planning/writing-style.md for the course voice.
